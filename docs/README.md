# Документация RedComplex

Здесь собраны практические правила работы с основными подсистемами RedComplex:
контекстами команд, документами, консолью и системным маршрутизатором.

Документация описывает текущее поведение кода, а не только желаемое. Если
поведение меняется, соответствующий раздел нужно обновлять вместе с кодом.

## Быстрый старт

Открыть документ из консоли:

```text
documents action=create, target=system-router, id=router
```

Посмотреть доступные команды:

```text
help
```

Посмотреть узлы и блоки SystemRouter:

```text
system-router-routes
system-router-blobs
```

## Соглашения

- Команды и контексты — это **связующая шина** между модулями. Модули не должны
  обращаться к чужим виджетам напрямую, если можно обменяться контекстом.
- Состояние документа хранится в переменных его контекста, а не в глобальных
  синглтонах.
- Для ошибок и предупреждений используется `printError()` / `printWarning()`;
  диалоги допустимы только для вопросов пользователю (выбор файла, подтверждение
  удаления и т. п.).
- Любое изменение схемы БД оформляется миграцией в
  `src/Configurations/stores/migrations/<store>/` и добавляется в
  `src/Configurations/bootstrap.yaml`.

## Исходники

- `src/Libs/Engine/scripting/` — контексты, команды, парсер.
- `src/Libs/Engine/ui/` — `MainWindow`, `DocumentWidget`, панели.
- `src/Libs/BaseWidgets/tree_view/lazy_load/` — ленивое дерево.
- `src/Content/DatabaseModule/` — доступ к SQLite/SQLCipher и резервное копирование.
- `src/Content/FetchApiModule/` — REST-запросы: модель, сервис, документ и команда.
- `src/Content/SystemRouter/` — маршрутизатор, узлы, команды и блоки.
- `src/Content/ConsoleModule/` — консольные команды `help` и `echo`.
